Key Architectural Finding: In iterative solvers with fine temporal or spatial discretization (such as syntx.tvf), querying .item() inside velocity magnitude clamping and epoch loss evaluation forces the CPU to stall until the accelerator finishes execution and transfers scalars across PCIe / Unified Memory. Eliminating these barriers enables continuous asynchronous kernel pipelining, delivering an immediate 15.6% speedup with zero loss in numerical or topological precision.
